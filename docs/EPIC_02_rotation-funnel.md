## 1. 개요

EPIC 01의 필터링을 통과한 유저들이 실제로 만남을 이어가는 **5단계 퍼널 구조**를 정의합니다.
**대화의 인상을 외모보다 강하게 우선시**하는 것이 이 퍼널의 핵심 철학입니다.
사진은 대화 인상에 대한 1단계 선택을 완료한 유저에게만 해금되며, 외모는 관계 형성의 보조 요소로 기능합니다.

---

## 2. 퍼널 흐름

```
[Phase 1]          [Phase 2]                [Phase 3]
블라인드 태그 매칭 → 타임박스 탐색 대화      → 최종 선택 라운지
(사진 비공개)        (15분, 텍스트/보이스)      (대화 요약 + 사진 해금 선택)
                     + 대화 도우미 상시 노출
                                                      ↓
                                             [Phase 4]
                                             수락(2단계) / 보류 / 선택 안 함
                                             (사일런트 드롭 원칙)
                                                      ↓
                                             [Phase 5]
                                             영구 대화방 오픈
                                             (대화량 한도 적용)
```

---

## 3. Phase 1 — 블라인드 태그 매칭

- 사진 **비공개** 상태로 성향/가치관 태그만으로 매칭 그룹 구성
- 사진 등록 유저의 경우 AI가 분석한 **외모상 태그** (예: `#두부상`) 추출 및 제공
- 사진 등록 유저에게 **매칭 우선순위 가산점** 부여

---

## 4. Phase 2 — 타임박스 탐색 대화

### 기본 구조
- 정해진 시간 (**15분**) 동안 시각적 요소를 철저히 배제
- **익명성이 보장되는 텍스트 또는 보이스**로만 1:1 릴레이 대화 진행
- 인지 과부하 방지를 위한 시간 제한 구조

### 🆕 대화 도우미 (Conversation Guide)
- 대화창 **상단에 상시 노출**되는 AI 대화 유도 에이전트
- 매칭된 상대방의 가치관 태그를 기반으로 **맥락에 맞는 대화 주제를 실시간 제안**
- 예시: *"이 주제로 대화해보세요 💬 → 둘 다 여행을 좋아하시네요. 가장 기억에 남는 여행지는 어디인가요?"*
- 유저가 직접 닫을 수 있으나, 닫아도 일정 주기마다 새 주제 제안이 갱신됨
- 목적: 대화 시작의 심리적 장벽 해소 및 대화 밀도 향상

---

## 5. Phase 3 — 최종 선택 라운지

> **핵심 변경:** 사진은 세션 종료 후 자동 공개되지 않습니다.
> 대화 인상에 대한 **1단계 선택을 완료한 유저에게만** 사진 해금 권한이 부여됩니다.

### 5-1. 라운지 진입 조건
- 일일 로테이션 대화 (최대 3인) 세션이 **모두 종료된 후** 접근 가능
- 유효 시간: 대화 종료 시점부터 **24시간** (자정 기준 동기화)

### 5-2. 🆕 대화 요약 및 전문 열람
라운지에서 상대방 카드를 확인하기 전, 아래 두 가지 방법으로 대화를 복기할 수 있습니다:

| 기능 | 설명 |
|------|------|
| 대화 요약 | AI가 오늘 대화의 핵심 주제와 인상을 2~3문장으로 요약 제공 |
| 대화 전문 보기 | 오늘 나눈 대화 전체를 스크롤하여 다시 읽기 가능 (24시간 이내) |

### 5-3. 🆕 사진 해금 프로세스 (1단계 선택)

```
라운지 진입
  → 상대방 카드 확인 (사진은 가상 이미지로 잠금 상태)
  → "이 대화가 마음에 드셨나요?" (1단계 선택)
       ↓ YES 선택 시
  → "사진을 확인할 수 있어요" 안내 노출
  → 가상 프로필 이미지 터치 → 실제 사진 해금
       ↓
  → 2단계 선택으로 이동 (Phase 4)
```

- **1단계 선택(YES)은 상대방에게 알림이 발송됨** → 상대방도 나의 선택 사실을 인지
- 1단계 선택 전에는 사진 확인 불가 → 대화 인상이 판단의 1순위

---

## 6. Phase 4 — 수락 / 보류 / 사일런트 드롭

### 6-1. 선택지 구조

사진 해금 후 유저는 아래 세 가지 중 하나를 선택합니다:

| 선택지 | 설명 | 상대방 알림 |
|--------|------|------------|
| 💚 수락 (2단계) | 매칭 성사를 원함 → 양측 모두 수락 시 영구 대화방 오픈 | ✅ 알림 발송 |
| ⏳ 보류 | 아직 결정을 내리기 어려움 → 24시간 유효 시간 내 언제든 변경 가능 | ❌ 알림 없음 |
| 선택 안 함 | 매칭을 원하지 않음 → 조용히 종료 (사일런트 드롭) | ❌ 알림 없음 |

> **알림 원칙:** 알림이 발송되는 경우는 오직 상대방이 **1단계 선택(YES) 또는 2단계 수락**을 했을 때뿐입니다.

### 6-2. 보류 만료
- 보류 상태는 **대화 만료 시간(24시간)과 동일하게 자동 소멸**
- 만료 시 자동으로 '선택 안 함' 처리 (사일런트 드롭)

### 6-3. 🆕 선택 안 함 이후 — 차단 옵션

'선택 안 함' 선택 직후 아래 추가 질문이 노출됩니다:

> *"이 상대방과 앞으로 다시 만나지 않으시겠어요?"*
> - **다시 만나지 않기** → 차단 리스트에 추가, 이후 매칭에서 영구 제외
> - **그냥 두기** → 차단 없이 조용히 종료, 추후 매칭 가능성 유지

### 6-4. 매칭 결과 시나리오

| 시나리오 | 결과 |
|---------|------|
| 양측 모두 2단계 수락 | **영구 대화방** 오픈 → Phase 5 진입 |
| 한 명이라도 '선택 안 함' 또는 보류 만료 | **알림 없이 조용히 종료** (사일런트 드롭) |

---

## 7. Phase 5 — 매칭 성사 후 영구 대화방

### 7-1. 입장
- 양측 2단계 수락 확인 즉시 **영구 대화방** 오픈
- 상대방의 실제 이름(또는 닉네임), 사진, 가치관 태그가 상단에 노출

### 7-2. 🆕 대화량 한도

후속 대화가 길어지면서 발생하는 서버 자원 비용을 관리하고, 유저가 오프라인 만남으로 자연스럽게 이동하도록 유도하기 위해 **대화량 한도**를 적용합니다.

| 항목 | 기본 제공 | 추가 방법 |
|------|----------|----------|
| 기본 대화량 | 일정 메시지 수 또는 일정 기간 제공 (추후 수치 확정) | - |
| 한도 초과 시 | 대화 일시 중단 안내 노출 | 광고 시청 또는 인앱 결제로 해금 |

> **설계 의도:** 연락처 교환이나 오프라인 만남으로의 자연스러운 이탈을 지원하되,
> 프라이버시를 중시하는 유저(스토킹 우려 등)를 위한 앱 내 안전한 대화 채널도 유지합니다.
