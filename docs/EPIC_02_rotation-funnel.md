## 1. 개요

EPIC 01의 필터링을 통과한 유저들이 실제로 만남을 이어가는 **4단계 퍼널 구조**를 정의합니다.
외모 노출을 최대한 후순위로 미루고, 대화와 가치관 중심으로 관계를 형성하도록 설계되었습니다.

---

## 2. 퍼널 흐름

```
[Phase 1]         [Phase 2]           [Phase 3]              [Phase 4]
블라인드 태그 매칭 → 타임박스 탐색 대화 → 비동기 사진 공개 → 상호 수락 / 사일런트 드롭
(사진 비공개)       (10분, 텍스트/보이스)  (최종 선택 라운지)   (영구 대화방 or 조용한 종료)
```

---

## 3. Phase 1 — 블라인드 태그 매칭

- 사진 **비공개** 상태로 성향/가치관 태그만으로 매칭 그룹 구성
- 사진 등록 유저의 경우 AI가 분석한 **외모상 태그** (예: `#두부상`) 추출 및 제공
- 사진 등록 유저에게 **매칭 우선순위 가산점** 부여

---

## 4. Phase 2 — 타임박스 탐색 대화

- 정해진 시간 (예: **10분**) 동안 시각적 요소를 철저히 배제
- **익명성이 보장되는 텍스트 또는 보이스**로만 1:1 릴레이 대화 진행
- 인지 과부하 방지를 위한 시간 제한 구조

---

## 5. Phase 3 — 세션 종료 후 비동기 사진 공개

- 일일 로테이션 대화 (최대 3인) 세션이 **모두 종료된 직후** 실행
- **최종 선택 라운지**에서 대화 상대방들의 프로필 사진 + 성향 요약본 일괄 공개
- 실시간 대화의 압박 없이 차분한 탐색 보장

---

## 6. Phase 4 — 상호 수락 및 사일런트 드롭 (Silent Drop)

| 시나리오 | 결과 |
|---------|------|
| 양측 모두 수락 | 상시 접속 가능한 **영구 대화방** 오픈 |
| 한 명이라도 거절 | **알림 없이 조용히 매칭 종료** (사일런트 드롭) |

- 다음 단계 진행 여부를 **각자 독립적으로** 선택 → 상대방의 결정을 알 수 없음
- 거절 알림 없음 → 심리적 부담 최소화
