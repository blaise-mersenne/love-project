## 1. 개요

매칭 성사 전, 백그라운드에서 작동하는 **원천 필터링 알고리즘**을 정의합니다.
유저가 직접 보거나 선택하기 전에, 조건에 맞지 않는 상대를 사전 차단하여 매칭의 질을 높이는 것이 핵심입니다.

---

## 2. 히든 불호 (Kill-Switch) 필터링

### 개념
유저가 설정한 **절대 불가 조건**을 백그라운드 알고리즘에서 원천 차단하여 불필요한 매칭을 방지함.

### 조건 예시
- 흡연 여부
- 특정 지역 거주
- 본인 키 기준 ±5cm 초과
- (추후 확장 예정)

### 특징
- 유저에게 **직접 노출되지 않음** → 상대방이 어떤 조건으로 필터링됐는지 알 수 없음
- 매칭 풀에 진입하기 전 단계에서 작동

---

## 3. 생활 반경 앵커 (Anchor)

### 개념
실시간 GPS가 아닌, 본인의 **주요 생활 거점**을 기준으로 활동 반경 내 유저를 우선 매칭하여 현실적인 오프라인 만남 확률을 높임.

### 거점 설정
- 최대 **2개** 등록 가능 (집, 직장 또는 학교)
- 실시간 위치 추적 **없음** → 프라이버시 보호
