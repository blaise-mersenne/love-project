## 1. 개요

서비스의 **운영 정책**과 **수익 구조**를 정의합니다.
희소성 기반의 세션 제한과 FOMO(기회 상실) 심리를 활용한 수익화 모델을 중심으로 설계되었습니다.

---

## 2. 세션 규모 제한 (Traffic Control)

- 1일 기본 로테이션 대화 가능 인원: **최대 3인**
- 목적: 초기 트래픽 관리 및 **희소성 유지**
- 제한 초과 시 → 유료 과금 또는 광고 시청으로 추가 가능 (아래 수익화 모델 참고)

---

## 3. 수익화 모델

### 3-1. FOMO (기회 상실) 기반 과금

오늘 추천 리스트에 떴으나 기본 3인에 포함되지 않은 유저에 대해 아래 두 가지 경우 과금 적용:

| 상황 | 설명 |
|------|------|
| 먼저 대화 걸기 | 명일 리스트 갱신 전, 해당 유저에게 먼저 접근 시도 |
| 추가 매칭 | 기본 3인 초과, 추가 매칭 희망 시 |

### 3-2. 보상형 광고

- 시간 대기 또는 추가 1인 매칭 시 **동영상 광고 시청 옵션** 제공
- 광고 시청 완료 시 → 추가 매칭 1회 획득

### 3-3. 인앱 결제 (유료 재화)

| 기능 | 설명 |
|------|------|
| 추가 매칭권 | 즉각적인 추가 매칭 1회 구매 |
| 호감 유저 외모 태그 열람 | 나에게 호감을 표시한 유저의 외모상 태그 우선 확인 |
| 기타 프리미엄 기능 | 추후 확장 예정 |
