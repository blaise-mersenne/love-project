# 💝 Love Project

> 외모 중심의 스와이프를 넘어, 가치관과 조건이 맞는 상대를 만나는 하이퍼 매칭 서비스

---

## 서비스 한 줄 정의

**히든 불호(KillSwitch) 필터링** + **생활 반경 앵커** + **디지털 로테이션 퍼널**을 결합하여,
진성 유저들이 안전하고 밀도 높은 만남을 경험할 수 있도록 설계된 매칭 플랫폼.

---

## 핵심 차별점

| 기존 데이팅 앱 | Love Project |
|--------------|-------------|
| 외모 기반 스와이프 | 가치관/조건 기반 필터링 먼저 |
| 무제한 매칭 → 피로감 | 1일 최대 3인 제한 → 집중도 |
| 실시간 사진 노출 | 대화 후 비동기 사진 공개 |
| 거절 알림 → 상처 | 사일런트 드롭 → 조용한 종료 |
